# SyncManager lastDocId Persistence (Room v9) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist the compound-cursor docId tiebreakers (`subs_last_id`, `playlists_last_id`, `favorites_last_id`) in the `sync_state` Room table so they survive process death, eliminating the post-restart row-drop window on cursors tied to the same millisecond.

**Architecture:** R3/R4 P1 added in-memory compound-cursor tiebreakers (`lastIds` map in `SyncManager.pullAllLocked`) to handle multiple rows sharing the same `updatedAt`. The map is reset on every process start; if the first pull after restart hits a page boundary where the last row in the previous run's page and the first row in the next page share a millisecond, the tied row gets dropped. The fix is a Room v9 migration adding three NULLABLE columns to `sync_state` and threading them through `SyncManager`.

**Tech Stack:** Android Room 2.6, Kotlin coroutines, Hilt DI, Robolectric (for migration test), JUnit 4.

**Spec source:** Cubic R7 P1 finding (Plan 0 → HEAD review, 2026-05-15). R3/R4 compound cursor doc: `docs/superpowers/specs/2026-05-12-plan-d-sync-engine-design.md` §10.

- [ ] **Step 2: Persist after each page write**

After the existing `cursors["subscriptions"] = it` (and siblings), within the `body.subscriptions.nextCursor?.let { ... }` block, switch the `syncState.upsert(...)` call to include the docId. Locate the existing upsert:


Replace with:

```kotlin

// or the tiebreaker drift detection in subsequent pulls misfires.

syncState.upsert(SyncStateEntity(
    entity_type = "subscriptions",
    user_id     = uid,
    cursor_ts   = it,
    last_doc_id = lastSubId,
    updated_at  = System.currentTimeMillis()))
cursors["subscriptions"] = it
lastIds["subscriptions"] = lastSubId
```

Repeat the same shape for the `body.playlists.nextCursor?.let { … }` and `body.favorites.nextCursor?.let { … }` blocks.

```kotlin
import androidx.room.Room
import androidx.test.platform.app.InstrumentationRegistry
import com.albunyaan.tube.data.local.AppDatabase
import com.albunyaan.tube.data.local.SyncStateEntity
import kotlinx.coroutines.test.runTest

import org.junit.Before
import org.junit.Test
import org.junit.runner.RunWith
import org.robolectric.RobolectricTestRunner
import org.robolectric.annotation.Config
import retrofit2.Response
import org.junit.Assert.assertEquals

@RunWith(RobolectricTestRunner::class)
@Config(sdk = [31])
class SyncManagerCursorPersistTest {
    private lateinit var db: AppDatabase
    private lateinit var api: FakeSyncApi
    private lateinit var sm: SyncManager

    @Before fun setUp() {
        val ctx = InstrumentationRegistry.getInstrumentation().targetContext
        db = Room.inMemoryDatabaseBuilder(ctx, AppDatabase::class.java).build()
        api = FakeSyncApi()
        sm = SyncManager(api, db, db.subscribedChannelDao(), db.savedPlaylistDao(),
                         db.favoriteVideoDao(), db.syncStateDao(), db.accountBindingDao())
    }

    @After fun tearDown() = db.close()

    @Test fun pullAll_resumesFromPersistedDocId() = runTest {
        // Seed sync_state as if a prior run had left lastIds={"subscriptions":"UC-prev"}.
        db.syncStateDao().upsert(SyncStateEntity(
            entity_type = "subscriptions",
            user_id     = "uid",
            cursor_ts   = 100L,
            last_doc_id = "UC-prev",
            updated_at  = 0L))

        // Capture what the API sees.
        var capturedLastSubId: String? = "MARKER"
        api.pullResponse = { req ->
            capturedLastSubId = req.subscriptionsLastId
            Response.success(emptySyncResponse())
        }

        sm.pullAll("uid")

        assertEquals("UC-prev", capturedLastSubId)
    }
}
```
